## 🧪 Featured Projects

### 1. Tuberculosis Prediction Using Machine Learning

**Technologies:** Python, Pandas, NumPy, Scikit-learn, WHO Data, World Bank API

- Developed a machine learning project to explore tuberculosis incidence using global health and socioeconomic indicators.
- Integrated WHO tuberculosis data with World Bank development indicators.
- Explored relationships between TB incidence, population characteristics, economic indicators, HIV prevalence, and health expenditure.
- Applied exploratory data analysis, regression modeling, and model evaluation using MAE, RMSE, and R².

🔗 **Repository:** [MachineLearning](https://github.com/nabin1344/MachineLearning)

### 2. Spatial Epidemiology of Tuberculosis in Nepal

**Technologies:** R, QGIS, GeoDa, Spatial Statistics

- Investigated geographic patterns and spatial clustering of tuberculosis across municipalities in Nepal.
- Applied spatial statistical methods to explore disease distribution and socio-environmental determinants.
- Contributed evidence to understanding geographic inequalities in tuberculosis burden.

📄 **Publication:** [Municipality-Level Spatial Clustering and Socio-Environmental Determinants of Tuberculosis in Nepal, 2019–2024](https://doi.org/10.1186/s12879-026-14265-8)
